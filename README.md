# 瑞多售后服务 Demo V3.4

静态交互演示。V3.4 新增区域经理独立手机端，包含辖区工单、异常待办、消息入口、工单详情和允许阶段内的改派。

业务主流程仍为：客服核实后按区域自动直派当地服务商。区域经理可在手机端查看本人负责区域，正常工单不形成审批待办，异常和改派按需处理。

## 在线版本目录

- `/`：当前 V3.4
- `/v3.4/`：V3.4 固定快照
- `/v3.3/`：上一版 V3.3 固定快照

## 发布说明

将本目录全部文件上传到 GitHub Pages 仓库根目录。不要删除 `v3.3/` 与 `v3.4/`，后续版本继续用新版本目录保留历史快照。

本 Demo 不依赖服务器或外部资源，所有操作只修改当前浏览器的演示数据。推送、短信、支付均为模拟；不包含真实后台数据、账号密码、客户信息或收款资料。
