# 瑞多售后服务 Demo V3.3

静态交互演示，包含自动分配、服务商及售后履约、区域人员配置、模拟消息和角色权限。

## 发布到 GitHub Pages

1. 将本目录的 index.html、.nojekyll 和 README.md 上传至选定仓库的根目录。
2. 仓库 Settings → Pages → Build and deployment，Source 选择 Deploy from a branch。
3. 选择实际上传的分支（通常为 main）和 / (root)，保存。
4. 等待 GitHub 显示发布成功，复制 Pages 页面返回的实际网址给开发。

默认项目站网址通常为 https://<账号>.github.io/<仓库名>/，应以发布成功页面的真实地址为准。
仓库文件浏览页本身不是交互 Demo 地址。

本 Demo 不依赖服务器或外部资源；也可以在电脑浏览器直接打开 index.html。
所有操作只修改当前浏览器中的演示数据；推送、短信和支付均为模拟。
旧版 Demo 未覆盖。后续更新应保留本次快照；同一发布地址可通过版本子目录继续保留历史版本。
公开 GitHub Pages 页面可被其他人访问。此包包含产品流程和示例数据，不包含真实后台数据、账号密码或收款资料。
